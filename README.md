# こども食堂レスキュー 🍙

子ども食堂と、企業・地域住民をつなぎ、**食材・資金・人手**の支援を地域全体で行うためのアプリです。
SDGs 目標2「飢餓をゼロに」の達成をめざします。

> 本アプリは高校生による試作版です。表示される団体・募集はすべて架空のデモデータです。

- パソコン・スマートフォンのブラウザ、iPhone・Android で同じコードが動きます（Expo / React Native）
- データベースと認証は Supabase を使います

## はじめかた

### 必要なもの

- [Node.js](https://nodejs.org/) 22 以上
- [Git](https://git-scm.com/)
- スマートフォンで確認する場合：App Store / Google Play の「Expo Go」アプリ

### インストールと起動

```bash
git clone https://github.com/hayakawa5602/kodomo-shokudo-rescue.git
cd kodomo-shokudo-rescue
npm install
cp .env.example .env      # Windows の場合は copy .env.example .env
npm run web               # ブラウザで開く
```

スマートフォンで確認する場合は `npm start` を実行し、表示されたQRコードを Expo Go で読み取ります。

### 環境設定（.env）

| 変数 | 内容 |
|---|---|
| `EXPO_PUBLIC_SUPABASE_URL` | Supabase の Project URL |
| `EXPO_PUBLIC_SUPABASE_ANON_KEY` | Supabase の anon（公開用）キー |
| `EXPO_PUBLIC_APP_ENV` | `demo` のときはデモデータのみ表示 |

Supabase の準備手順は [docs/supabase-setup.md](docs/supabase-setup.md) を見てください。
未設定のままでも、デモ表示で画面を確認できます。

> ⚠️ **service_role キー・データベースのパスワードは、`.env` を含めどのファイルにも書かないでください。** `.env` は GitHub に上がらない設定になっています。

## フォルダ構成

```
src/app/          画面（ファイル＝画面。Expo Router）
  (auth)/         ログイン・新規登録・利用者区分の選択
  (app)/          ログイン後の画面（ホーム・募集・申込・通知・マイページ等）
  admin/          管理者専用画面
src/components/   ボタン・カードなどの共通部品
src/lib/          Supabase接続、区分の定義、入力チェック
src/theme/        色・文字サイズ
src/demo/         デモデータ（本番では使わない）
supabase/         データベース定義（migrations）と権限テスト（tests）
docs/             設計メモ・手順書
```

## デザイン

緑（安心・信頼）× 淡いクリーム（温かみ）× オレンジ（行動を促すボタン）。
文字は大きめ、ボタンは高さ52px以上で、子どもや高齢者にも押しやすくしています。

## セキュリティ

詳しくは [docs/design.md](docs/design.md)。主なポイント：

- 全テーブルで Row Level Security を有効化
- 管理者権限はアプリから付与できない（登録時に指定しても無効化）
- 審査の承認・却下は管理者専用のデータベース関数でのみ実行し、操作履歴を自動記録
- 電話番号・住所は、承認された申込の相手どうしにしか見えない
- 期限切れ・開封済みの食品は申込できない
- 資金支援は法的確認が完了するまで無効
